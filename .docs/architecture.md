# 🏛️ Arquitetura e Decisões

## Tech Stack
* **FastAPI (Python):** Produtividade, validação automática (Pydantic) e Swagger nativo.
* **PostgreSQL:** Garantia de consistência ACID para transição de status.
* **SQLAlchemy & Alembic:** ORM e migrações do banco.
* **Docker Compose:** Orquestração da API e do Banco.
